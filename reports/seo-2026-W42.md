## Technical Issues Found

### High Priority

- **Wrong social share URLs in BlogDetail** (`src/views/Blog/Detail/index.tsx` lines 45, 51) — Social share links use `/blog/detail/${post.slug}` but the actual URL is `/blog/${post.slug}`. Every social share button on every blog post points to a 404. Fix: remove the `detail/` segment from both href strings.

- **Empty alt tags on all blog post images** — All 7 blog posts have `feature_image_alt: ""`. Additionally, all inline images inside blog post HTML have `alt=""`. Empty alts are both an accessibility violation and a missed indexing opportunity for image search. Fix: add descriptive alt text to `feature_image_alt` for each post, and update inline `<img>` tags in the HTML content.

### Medium Priority

- **Feature image not rendered on blog post detail pages** — `src/views/Blog/Detail/index.tsx` renders only `post.html` via `dangerouslySetInnerHTML` and never displays the `feature_image`. The list view shows thumbnails, but the article page itself has no hero image. This reduces visual quality and misses a chance to get image alt text indexed for the article.

- **G2 profile unclaimed (zero reviews)** — `g2.com/products/passdropit` is live but unclaimed and has no reviews. Claiming it is free and a low-effort DA/trust signal. G2 pages rank well for SaaS comparison searches.

### Low Priority / Confirmed OK

- **Sitemap** (`src/app/sitemap.ts`) — Correct. All 7 blog posts included, all key static routes included. No `/download/` pages (correctly excluded).
- **Robots** (`src/app/robots.ts`) — Correct. `/admin/`, `/user/`, `/api/`, `/download/`, and other private paths disallowed. Sitemap URL is declared.
- **Canonical URLs** — Correctly set via `generateMetadata()` in `src/app/blog/[id]/page.tsx`. Each blog post gets its canonical constructed from `SITE_URL + /blog/ + slug`.
- **Static file conflicts** — No `public/robots.txt` or `public/sitemap.xml` present. (Previously flagged in backlog; already resolved or never existed.)
- **JSON-LD schema** — Article schema with `datePublished`, `dateModified`, and `author` present on all blog post pages.

## Opportunities

### Long-tail Keywords with Low Current Competition

1. **`see who downloaded my dropbox file`** / **`track dropbox downloads`** — Multiple Dropbox forum threads confirm this is a highly-searched pain point with no good free solution. Passdropit's IP tracking solves this exactly. No dominant article ranks for it. Blog post already in backlog queue.

2. **`dropbox link expiry date free`** / **`set expiry on dropbox link without paid plan`** — Dropbox's own expiry feature requires paid plans. Users on forums actively ask for free alternatives. Passdropit offers this. No content on this topic on the site yet. **New backlog item.**

3. **`share sample pack download link protected`** — Searches around music producers sharing Lightroom presets and sample packs show widespread use of unprotected Dropbox/Google Drive links. No competitor has a direct tutorial for this audience. High overlap with Passdropit's primary user base.

4. **`how to prevent dropbox link from being shared`** / **`restrict who can access dropbox link`** — Very high intent. Organic search results are fragmented. Passdropit's password + download limit combo addresses this directly.

### Featured Snippet Opportunities

- "Can you see who downloaded a file on Google Drive?" — Answer is "no, not with a free account." A blog post that frames Passdropit as the solution could capture the featured snippet. No current Passdropit content targets this question.

### Competitor Gap

Papermark dominates SEO but is repositioning as a full document-sharing platform (NDA gates, watermarks, enterprise). Passdropit's unique angle — **no re-upload required, works directly with existing Dropbox/Google Drive/Notion links** — is not being captured in any current blog content. This is the clearest brand differentiator and should be the lead in new content.
